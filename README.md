আমি একটা ক্লায়েন্টের কাজ পেয়েছি। আআ, সেই কাজটি হলো যে, তার একটি ই-কমার্স ওয়েবসাইট লাগবে। আ, যেটি বাংলাদেশ রিলেটেড। যেমন আমি বলি তার প্রোডাক্টগুলো। আ, সে সাধারণত বাংলাদেশি আম, আ, আমের আচার, তেঁতুলের আচার, রসুনের আচার, আ, খেজুর, খাঁটি সরিষার তেল, দেশি, আ, যাবতীয় বিষয় নিয়ে। তো আমি চাচ্ছি তুমি তার জন্য একটি প্রফেশনাল, আ, ওয়েবসাইট তৈরি করো এবং তোমার ধারণার জন্য তার Facebook পেজের লোগো এবং একটি ব্যানার দিচ্ছি। আ, সেগুলো থেকে কালার ধারণা, ফ্রন্টের ধারণা সমস্ত কিছু পেতে পারো এবং এই তথ্যগুলো ব্যবহার করে একদম প্রফেশনালি আমার জন্য একটি, আ, functional ওয়েবসাইট তৈরি করো যেটি একদম প্রফেশনাল।
